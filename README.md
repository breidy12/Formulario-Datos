# 📝 Formulario de Datos Personales

Una página web creada con **HTML y CSS** para recopilar información personal de manera clara y organizada.  
Incluye campos para nombre, apellido, edad, teléfono, correo y cédula, con validación básica y un diseño moderno con fondo difuminado.

## ✨ Características
- Formulario responsivo y centrado en la pantalla.  
- Campos para nombre, apellido, edad, teléfono, correo y cédula.  
- Validación de cédula (solo números y 11 dígitos).  
- Diseño moderno con fondo oscuro y efecto blur.  
- Botón de envío con animación al pasar el cursor.

---

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **CSS3**
- **Visual Studio Code** (editor recomendado)
